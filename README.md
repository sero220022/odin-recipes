# odin-recipes
A simple recipe website built as part of The Odin Project - Foundations curriculum.

This project consists of a homepage that links to three different recipe pages. Each recipe page contains a description, an image, a list of ingredients, and step-by-step cooking instructions.

Features
Homepage with links to all recipes
Three individual recipe pages
Semantic HTML structure using headings, paragraphs, ordered lists, and unordered lists
Images with descriptive alt text for accessibility
Relative links for navigation between pages
Built With
HTML5
Git
GitHub
What I Learned

By completing this project, I practiced:

Creating a basic multi-page website
Structuring web pages with semantic HTML
Using headings, paragraphs, lists, links, and images
Writing descriptive alt attributes for accessibility
Organizing files and folders in a web project
Using relative paths to link between pages
Managing a project with Git and GitHub
Writing meaningful Git commit messages
